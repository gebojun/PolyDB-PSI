# PolyDB-PSI

PolyDB-PSI 是面向聚合物材料性质数据的 PSI 数据库与可靠性验证项目。

当前仓库包含已完成上传的 V11 重复 5 折交叉验证资料，目录已直接展开到仓库根目录：

- `config/`：工作流配置
- `input_data/`：输入数据
- `outputs/01_oof_predictions/`：OOF 预测结果
- `outputs/02_oof_reliability_scores/`：OOF 可靠性评分结果
- `AUTODL_DEPLOY.md`、`QUICKSTART.md`、`V11_METHOD.md`：部署、快速开始和方法说明

项目名称：**PolyDB-PSI**  
默认分支：**main**
